# pbcomponents-storybook

Локальный playground для просмотра компонентов `@prosazhin/pbcomponents` при разработке. Никуда не публикуется и не собирается в CI.

Документация библиотеки: https://prosazhin.dev/docs/pbcomponents

```bash
npm run dev
```

Из корня репозитория: `npm run dev` поднимает watch-сборку библиотеки и Storybook одновременно.
